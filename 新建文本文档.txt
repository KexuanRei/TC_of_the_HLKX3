
## 四、阅读操作（快捷键）

| 按键 | 功能 |
| --- | --- |
| `A` 或 `←` | 上一页 |
| `D` 或 `→` | 下一页 |
| `Q` 或 `Esc` | 立即关闭（自动保存进度） |
| `E` | 打开设置菜单（详见下一节） |
| 鼠标滚轮 | 上一页 / 下一页 |
| `+` 或 `=` | 字号放大 |
| `-` 或 `_` | 字号缩小 |
| `PageUp` | 上一页 |
| `PageDown` 或 `空格` | 下一页 |
| `T` | 切换「窗口置顶」开关 |
| `P` | 显示 / 隐藏右下角页码 |

---

## 五、设置菜单（按 `E` 打开）

按 `E` 后会弹出带序号的菜单，**直接按对应的数字键**即可执行，无需鼠标点击：

| 序号 | 菜单项 | 操作方式 |
| --- | --- | --- |
| `1` | 更改窗口大小 | 弹出对话框，输入**宽度**和**高度**，点「确定」完成（范围 100~4000 px） |
| `2` | 更改字号 | 弹出对话框，输入**字号**，点「确定」完成（范围 8~200 px） |
| `3` | 更改字体透明度 | 拖动滑块调整（0 完全透明 ~ 255 完全不透明），实时预览，点「确定」保存 |
| `4` | 更改字体颜色 | 打开调色板选择颜色，选好后点「确定」 |
| `5` | 退出阅读器 | 立即关闭并保存进度 |

> 菜单里数字后面的下划线，就是「按这个数字键即触发」的提示。
